## Notes / caveats
- F3/F13/F19 maps show **spatial-mean |err|** (unweighted within a latitude when zonal), while the headline RMSE is **cos(lat)-weighted**; magnitudes differ, trends agree.
- F10 (truth-model robustness T0-T3) is **deferred to Phase 2** (requires re-tuning localization/inflation per truth model).

## Evidence for reliability
1. Both temporal directions improve (F1, F2, F19).
2. Negligible seed dependence (F6).
3. Smooth, non-fragile parameter dependence (F7).
4. Structural, not scalar/diagonal (F11, F12, F13, F14).
5. Standard DA diagnostics improve (F3, F4, F5), but improvement is partial (F1, F3, F5, F18).
