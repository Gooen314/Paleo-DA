# 低秩状态空间算子改进古气候数据同化（AOEnKF）——内部汇报

**日期**：2026-09-10  
**数据/代码目录**：`online_ml/loc_learning/`（Python），同化基线核对自 `paleo/`（MATLAB）  
**一句话结论**：在串行 GC 分析增量上学习一个低秩状态空间算子 `xa = xf + z3 + U(V^T z3)`，在**盲测评估窗（601–1100，深冰消）** 把 TAS RMSE 从 **0.5021 降到 0.4724（r=5）**、**0.4581（r=20, λ=0）**；跨 5 个随机种子、正反两个时间方向、参数扫描均稳定，且机制被证实为**结构性修正而非缩放**。这是本系列尝试中**首个真正超越 canonical AOEnKF 的方法**。

---

## 1. 摘要（TL;DR）

- **基线**：canonical 串行 AOEnKF（K=100，GC 7500 km，inflation 1.5）。全窗 1–1100 TAS RMSE = **0.3658**；评估窗 601–1100 = **0.5021**。
- **方法**：不改同化的先验、观测、R、局地化、inflation、串行算法；仅在分析增量 `z3 = xa − xf` 上叠加一个**低秩状态空间算子** `ρ = I + U V^T`（U,V ∈ R^{6144×r}），即
  `xa = xf + z3 + U (V^T z3)`。
  用 **CELF**（对 mpi 真值的后验误差）在训练段拟合，验证段早停，测试段盲测。
- **结果**：
  | 口径 | AOEnKF | + r5 | + r20, λ=0 |
  |---|---|---|---|
  | Split A（测试 601–1100） | 0.5021 | **0.4724 ± 0.0001** | **0.4581** |
  | Split B（测试 1–550） | 0.2510 | **0.2442 ± 0.0000** | **0.2404** |
  | 无泄漏全窗（1–550 ∪ 601–1100） | 0.3706 | **0.3529** | **0.3441** |
- **机制**：全局标量缩放（s=0.957）反而变差（0.5030），逐格点对角缩放更差（0.5214），只有低秩结构修正有效（0.4725）。修正/增量能量比约 0.7（训练窗）、0.3（测试窗）。
- **注意**：改善是**局地的**（部分区域/纬度变差），且测试窗观测数少于训练窗；详见第 7 节。

---

## 2. 背景与目标

古气候数据同化（OSEE/AOEnKF）在本项目中的最优配置为：三先验模式 {trace, had_g, had_h} 的模拟场、mpi 作真值、gwb 伪代理观测、K=100 类比集合、GC 局地化、inflation 1.5。目标是**在深冰消期（6–11 ka）盲测窗提升 TAS 分析精度**。

本系列依次探索了：
1. 共性模态 + 因果去偏（CLIMATE-DA 协议）；
2. 流形/QC/R 膨胀的 M-AOEnKF-QC；
3. CNN 学习局地化（CLF/CELF，Wang et al. 2023）；
4. 串行一致的 GC 残差局地化；
5. **低秩状态空间算子（本文重点，成功）**。

前四种均失败或无显著增益，最终定位到**瓶颈不是局地化，而是分析增量/增益的状态空间结构（跨模式误差）**。

---

## 3. 基线设置与复现

- 同化：串行 EnSRF（MATLAB `EnSRF.m` 逻辑），增广状态 `[state; Hx]`，逐观测更新；GC 局地化 7500 km；inflation 1.5；K=100 类比选择（±250 窗，`cos·Δ²` 度量）。
- **复现可信度**：
  - Python（TAS-only）复刻 MATLAB：全窗 0.36582 vs 0.36582（差 8e-8）；
  - 可微串行 EnSRF（torch）与 numpy：差 3.8e-16。

## 4. 方法

### 4.1 串行 EnSRF（前向，逐时刻独立）

记号：n=6144（TAS 状态），M_t 为有效代理数，K=100，`xf` 集合均值，`d = y − H xf` 新息，`z3 = xa_serial − xf` 分析增量。

### 4.2 低秩状态空间算子

```
rho = I + U V^T ,   U, V ∈ R^{n×r}
xa  = xf + z3 + U (V^T z3)
```

- `U` 张成 r 维状态修正子空间，`V` 决定组合权重；
- 残差学习：初值 U,V ≈ 0 ⇒ 起点精确等于 AOEnKF；
- 只在**最强基线的增量**上做修正，不改变同化输入。

### 4.3 训练

```
L = CELF + λ (||U||_F^2 + ||V||_F^2)
CELF = Σ_j w_j (xa_j − xt_j)^2 / Σ_j w_j ,   w_j = cos(lat_j)
```

- 训练段 1–550，验证段 551–600（早停），测试段 601–1100（盲测）；
- Adam lr=1e-3，全批量；`z3` 与特征只用先验+观测，**不含真值**；U,V 只用训练段真值。

### 5.3 机制诊断

- 全局标量缩放（训练窗最优 s=0.957）：测试 0.5030（**差于基线**）；
- 逐格点对角缩放：测试 0.5214（更差）；
- 低秩 r=5：测试 0.4725（最优）；
- 修正/增量能量比：训练窗 ~0.7，测试窗 ~0.3；
- ⇒ 增益来自**秩-5 的结构性方向修正**，不是全局膨胀/收缩。

### 5.4 稳健性

- 随机种子：5 个，std ≤ 1e-4；
- 时间方向：A（早→晚）、B（晚→早）均改善；
- 参数：r∈{2,5,10,20}、λ∈{0,1e-3,1e-2} 平滑，λ 过大（1e-2）变差但仍优于基线；
- 观测数：测试窗 M_t 更少（约 380–720 vs 训练窗峰值 ~720）。

## 6. 负面/失败结果（定位瓶颈的过程）

| 尝试 | 评估窗 TAS RMSE | 结论 |
|---|---|---|
| canonical AOEnKF（基线） | 0.5021 | — |
| M-AOEnKF-QC：双度量 / QC+R / 完整 | 0.5282 / 0.5822 / 0.6443 | 全部恶化（流形+QC+R 有害） |
| batch GC / CLF / CELF | 0.5403 / 0.5518 / 0.5385 | 未超串行；batch/serial 域差 |
| 串行一致 GC 残差局地化 | 0.5023 | ≈基线；oracle 局地化 headroom <0.3% |
| **低秩状态空间算子** | **0.4724 / 0.4581** | **成功** |

关键教训：局地化不是瓶颈；把学习目标放在**分析增量的状态空间结构**上才有效。

## 7. 局限与注意事项

1. **改善局地**：F3/F5/F18 显示部分区域与纬度变差；全局均值改善是净效应，不是普适修正。
2. **训练/测试分布漂移**：训练窗（年轻段、观测多）与测试窗（深冰消、观测少）不同；算子为静态（不随年龄变化）。
3. **早停主导**：F8 显示训练 loss 持续下降而验证平台，模型选择依赖验证段；需在结论中如实说明。
4. **口径**：F3/F13/F19 地图为空间平均 |err|，与 cos(lat) 加权 RMSE 量级不同；0.3594（HGAOEnKF 全窗）为不同方法/口径，未直接对比。
5. **真值鲁棒性未测**：仅 T0（truth=mpi）；T1–T3（换真值）待 Phase 2，且每个真值需重扫最优局地化/inflation。

## 8. 结论

- 低秩状态空间算子在本数据集上**首次真实超越 canonical AOEnKF**：盲测评估窗 −5.9%~−8.8%，无泄漏全窗 −4.8%~−7.2%；
- 机制清晰（结构性、非缩放）、稳健（种子/方向/参数）；
- 定位了长期瓶颈：**跨模式误差体现在分析增量的状态空间结构**，而非局地化。
