# P0′ 诊断：CELF 残差 e_C 能否由 xb 预测？——不能

**日期**：2026-09-13
**问题**：拟把 xb 算子作为 CELF 的加性残差修正（`xa = xa_C + U(Vᵀ xb)`）。
本诊断检验其前提：`e_C = xa_C - xt` 是否可由 `xb` 预测。

## 结果

```
e_C 误差:        train 0.2375  val 0.2636  test 0.5261
e_C 秩能量(test): r5 83.1%  r20 91.4%  r50 95.4%      ← 低秩
e_C 秩能量(train): r5 44.3%  r20 67.3%  r50 82.1%     ← 训练段并不低秩（分布漂移）

预测 e_C 系数（ridge，val 选 λ），test 残差 RMSE:
  r=20  从 xb 预测: 0.8070      ← 远差于 CELF 本身
  r=20  从 zC 预测: 0.4855      ← 优于 CELF，接近阶段④实际 PQ 0.4759
  r=20  oracle 系数: 0.3845
  r=50  从 xb 预测: 0.8765
  r=50  从 zC 预测: 0.4896
  r=50  oracle 系数: 0.3453

直接加权相关: corr(e_C, xb) train -0.066, test -0.118（≈0）
              corr(e_C, zC) train -0.036, test -0.062（≈0）
```

## 结论

1. **e_C 不能由 xb 预测**：从 xb 预测的残差 0.807/0.877，远差于 CELF 单独（0.5261）；
2. **e_C 可由 z_C 预测**：0.486/0.490，与阶段④实际 PQ（0.4759）接近——说明该代理方法可靠；
3. 因此 **`xa = xa_C + U(Vᵀ xb)`（加性、输入 xb）缺乏依据**，预计学不出可迁移的修正；
4. 这与 P1/P2/P3 一致：以 xb 为输入的算子在评估窗不可迁移；有效路径仍然是**用增量 z_C 修正 CELF 残差**（阶段④，0.4759）。

## 建议
- **不训练**该方向（输入 xb 的 CELF 残差修正）；
- 若坚持，可立刻用向量化线性版做廉价确认（预计 test ≈ 0.6–0.8，劣于 CELF only）。
