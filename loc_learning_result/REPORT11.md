# REPORT 11：伪真值轮换 + 小样本组合（放弃）

**日期**：2026-09-13
**问题**：不用 MPI 真值训练；对 m∈{trace,had_g,had_h} 轮流以其为"假定真值"，全时段训练 (CELF_m, UV_m)；
再用 MPI 的 1–200 步学加权组合，应用到其余时段。目标：用 3 套解构成"可能真值的包络"。

---

## 1. 设置（按确认）

```
每个 m：
  池    = 其余 2 个模式（排除 m）
  观测  = pseudo_proxies_<m>（自己的伪代理）
  真值  = states_<m>
  训练  = 全时段 1-1050，早停 1051-1100
  CELF  : UNet(cin=4,base=32), rho=clip(1+net,0,1.5)
  UV    : r∈{5,20,50} × λ∈{0,1e-3} × 3 seeds，按 val 择优
测试时：全池（3 模式）+ MPI 观测；用 MPI 1-200 学单纯形权重
```

## 2. 中间结果

**CELF（对各自伪真值）**：trace val **0.607**（池够不到 trace）；had_g 0.080；had_h 0.065。
**UV 最优**：trace r=20/λ=0（val 0.396）；had_g r=5/λ=0（0.266）；had_h r=5/λ=0（0.245）。

**MPI 场景单体（TAS RMSE）**

| m | 1–200 | 201–1100 | 601–1100 |
|---|---|---|---|
| trace | 0.3110 | 0.4289 | 0.5799 |
| had_g | 0.3030 | 0.4004 | 0.5370 |
| had_h | 0.3083 | 0.4080 | 0.5476 |

**权重（MPI 1–200）**：单纯形最优 w=(trace 0.402, had_g 0.540, had_h 0.058)，F 仅从 17.9697 降到 17.8556（≈等权即最优）；无约束最小二乘 w=(0.400,0.579,0.046)。

## 3. 评估对比（TAS RMSE）

| 方案 | 201–1100 | 601–1100 |
|---|---|---|
| 单体最好（had_g） | 0.4004 | 0.5370 |
| **等权** | 0.3962 | **0.5312** |
| **加权（1–200 学）** | 0.3967 | 0.5323 |
| AOEnKF_Opt（基线） | 0.3819 | 0.5021 |
| GC+PQ | 0.3584 | 0.4720 |
| CELF+PQ | **0.3464** | **0.4763** |

## 4. 结论

1. **失败**：伪真值包络在 601–1100 为 0.531–0.532，**远劣于 AOEnKF_Opt 0.5021**，更逊 GC+PQ 0.472 / CELF+PQ 0.476；
2. 即使在 201–1100（**含训练时段的转导优势**），包络 0.396 仍**不如** AOEnKF_Opt 0.382、GC+PQ 0.358、CELF+PQ 0.346；
3. **权重不迁移**：在 1–200 学到的权重反而使 601–1100（0.5323）**略差于等权**（0.5312），再次印证跨窗非平稳；
4. **模式可达性严重不对称**：trace 相对 {had_g,had_h} 是"够不到"的（val 0.607），3 个模式无法构成 MPI 的可靠包络。

## 5. Caveat（必须记录）
- 全时段训练 + 同段评估 = 转导式（模型见过评估时刻的输入）——即便如此仍败给基线；
- 训练池 2 模式、测试池 3 模式；训练观测为 m 的伪代理、测试为 MPI 伪代理（两处域漂移）；
- 权重拟合仅 200 步、强自相关，选择噪声大。
