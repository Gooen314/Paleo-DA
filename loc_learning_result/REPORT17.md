# REPORT 17：迭代式低秩增益修正（形式 A）——1–2 步即饱和

**日期**：2026-09-13
**动机**：对 MPI（CELF 基）反复施加低秩增益修正 `x_{i+1} = x_i + U_i(V_i^T d_i)`，直到"修正值稳定"，看能否超越单步 UV。

## 1. 设置
```
真值/池 = MPI（pool = trace/had_g/had_h）
基 x_0 = CELF 分析（无加权版）= xf + z_C，val 0.2633 / test 0.5247
形式 A：d_i = y − H x_i（特征随迭代更新）；x_{i+1} = x_i + U_i (V_i^T d_i)，U:6144×r，V:1276×r
训练 1-550（CELF 损失，cos-lat 加权）；r ∈ {5,20,50}；3 个种子；小随机初值 1e-3；λ=0
固定 10 步（另跑对照：固定特征 d_0）
```

## 2. 结果（test 601–1100）

| 迭代 | greedy（更新特征） val / test | 固定特征 d_0 val / test |
|---|---|---|
| 0（CELF 基） | 0.2633 / 0.5247 | 同 |
| **1** | 0.2275 / **0.4907** | 0.2275 / 0.4907 |
| **2** | 0.2272 / **0.4902** | 0.2270 / 0.4901 |
| 3 | 0.2272 / 0.4903 | 0.2270 / 0.4901 |
| 4–10 | 0.2272 / 0.4902（**不再变化**） | 0.2270 / 0.4900（不再变化） |

**每步多秩（iter1，test 均值）**：r=5 → 0.4981；**r=20 → 0.4907（最优）**；r=50 → 0.4935。
**iter2** 后各秩几乎完全相同（≈0.4905）。

## 3. 结论
1. **1–2 步即饱和**：第一次修正吃掉全部可降量（0.5247→0.4902），之后残差不再含特征可预测成分——与理论预测一致（修正后残差与特征正交，`E[e z^T]=0`；可降量有效秩仅 ~5–20）。
2. **"更新特征"与"固定特征"几乎无差**（0.4902 vs 0.4900）：说明该迭代并未产生"乘积式"新解，本质仍是低秩累加。
3. **形式 A 弱于状态空间形式**：本次 0.4900–0.4907 **劣于**此前状态空间 UV 的 **0.4737**（CELF+UV）与 **0.4546**（Loc8000+UV）。即"U(V^T z)（z 在状态空间）"比"U(V^T d)（d 在观测空间）"更有效。
4. 因此**该迭代思路不带来增益**，原单步状态空间 UV 仍是更优参数化。

## 4. 实现注意（可复用）
- **λ=1e-3 会杀死学习**：在该参数化下正则梯度压过数据梯度（U,V 停在 ~1e-6）；必须用 **λ=0**（靠早停与低秩结构隐式正则）。
- 小随机初值有效（无零初始化鞍点问题）。
- 全流程向量化（D 用 1276 维、非活跃位点置 0），单模型 ~5 s。
