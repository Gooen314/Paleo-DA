# REPORT 20：以 CELF 为基的状态空间 UV 迭代（与 GC 基并排对照）

**日期**：2026-09-13
**口径**：truth=MPI、TAS-only、无加权类比选择；train 1-550 / val 551-600 / test 601-1100。
**形式**：`z_i = x_i − xf`，`x_{i+1} = x_i + U_i(V_i^T z_i)`，`U,V ∈ R^{6144×r}`；λ=0；r∈{1..30}×3 seeds；10 步。

## 1. 结果

| 迭代 | CELF 基（x_0=xf+z_C） val / test | GC(10000,1.0) 基 val / test |
|---|---|---|
| 0 | 0.2633 / 0.5247 | 0.2664 / 0.5118 |
| 1 | 0.2198 / 0.4742 | 0.2200 / 0.4536 |
| **2** | 0.2192 / **0.4732** | 0.2196 / **0.4520** |
| 3 | 0.2190 / 0.4781 | 0.2193 / 0.4553 |
| 4–10 | 0.2190 / 0.4781（不变） | 0.2192 / 0.4546（不变） |

## 2. 结论

1. **两基都 1–2 步饱和**；最优都在**第 2 步**（CELF 0.4732、GC 0.4520），第 3 步起 test 回升（过拟合）。
2. **两基的 val 收敛到几乎相同的值（≈0.219）**，但 **test 明显不同**（CELF 0.4732 vs GC 0.4520）——**val 无法区分两基，盲测窗才能**（再次体现非平稳）。
3. **CELF 基劣于 GC 基**：CELF 基迭代终点 0.4732 ≈ 单步 CELF+UV（0.4737），**迭代无增益**；GC 基迭代终点 0.4520（略优于单步 GC8000+UV 0.4546）。
4. 综合：**GC 基 + 状态空间 UV（单步或 it2）仍最好（0.4520）**；CELF 作为基不具备优势。
