# REPORT 22：CELF 增益的空间（Schur）低秩调制

**日期**：2026-09-13
**公式**：
```
d      = y − H xf
K_celf = ρ ∘ K0                          # CELF 增益（n × n_obs）
K_mod  = (1 + U Vᵀ) ⊙ K_celf             # 1 = 全 1 矩阵；U∈R^{n×r}, V∈R^{n_obs×r}
xa     = xf + K_mod · d                  （U=V=0 时精确等于 CELF 分析）
损失：CELF（cos-lat 加权状态 MSE），train 1-550 / val 551-600 / test 601-1100
```
即对 CELF 的 ρ（局地化/膨胀因子）做**逐元素 × 秩-r 低秩**的乘性调制。

## 1. 结果（test 601–1100 TAS RMSE，MPI，TAS-only，无加权）

| rank r | λ=0 test（3 seeds 均值±std） | λ=1e-3 test |
|---|---|---|
| 1 | 0.5215 ± 0.0005 | 0.5247 |
| 2 | 0.5187 ± 0.0007 | 0.5247 |
| 3 | 0.5171 ± 0.0002 | 0.5247 |
| 5 | 0.5144 ± 0.0011 | 0.5247 |
| 8 | 0.5117 ± 0.0003 | 0.5247 |
| 12 | 0.5094 ± 0.0003 | 0.5247 |
| **16** | **0.5076 ± 0.0008**（单 seed 最好 0.5065） | 0.5247 |
| 20 | 0.5085 ± 0.0002 | 0.5247 |
| 30 | 0.5077 ± 0.0007 | 0.5247 |

（CELF 基 = 0.5247；训练 300 epochs × 200 steps/epoch，Adam lr 1e-3，小随机初值。）

## 2. 结论

1. **机制起效**：Schur 增益调制随秩提升单调改善，最优 **r=16 → 0.5065–0.5076**（相对 CELF 0.5247 改善 **≈ −0.018**），并略优于最优 GC(10000)=0.5118。
2. **但弱于状态空间线性低秩**：同样在 CELF 基上，"线性低秩 on z（`xa=xa_C+U(Vᵀz)`）" 为 **0.4732**，远好于本方案 0.5065；GC(10000)+UV 为 **0.4520**。
   ⇒ **"在状态增量 z 上做低秩" 比 "在增益空间做 Schur 低秩" 更有效**。
3. **λ=1e-3 再次杀死学习**：该参数化下正则梯度过强，U,V 停在初值（test 恒为 0.5247 = CELF 基线）；必须 **λ=0**（与 `iter_uv` 的教训一致）。
4. 与 stage②（GC 增益的 MLP 乘性残差）对照：两者都说明"增益侧的乘性调制"存在但余量有限；真正的增益来自**状态空间**的低秩算子。
