# REPORT 23：迭代式 Schur 增益调制（更新特征）

**日期**：2026-09-13
**公式**：
```
x_0 = xf
d_i     = y − H x_i                        # 更新特征
K_celf  = ρ ∘ K0                           # 已缓存
x_{i+1} = x_i + [ (1 + U_i V_iᵀ) ⊙ K_celf ] d_i
损失：CELF（cos-lat 状态 MSE）；train 1-550 / val 551-600 / test 601-1100；λ=0
每步多秩选优：r ∈ {8,16,30} × 3 seeds，按 val 选；上限 N=10
停止：A) val RMSE 相对改善 <1% 连续 2 步；B) val 观测残差上升
```

## 1. 结果

| 迭代 | 选秩 | val RMSE | test RMSE | rel_impr | val 观测残差 |
|---|---|---|---|---|---|
| 0（xf） | — | 0.3427 | 0.6609 | — | 1.1124 |
| 1 | r30 | 0.2541 | 0.5165 | 25.8% | 1.0138 |
| 2 | r30 | 0.2459 | 0.5086 | 3.23% | 0.9895 |
| 3 | r30 | 0.2444 | 0.5090 | 0.62% | 0.9797 |
| **4** | r30 | 0.2428 | **0.5084** | 0.68% | 0.9734 |

→ **第 4 步触发停止准则 A（连续 2 步改善 <1%）**；准则 B 从未触发（观测残差单调下降）。

## 2. 结论
1. **1–2 步即饱和**：test 0.5165 → **0.5086**(it2) → 0.5090 → 0.5084(it4)，与**单步 Schur（0.5065）几乎相同**——迭代没有带来实质增益（甚至略差，属运行内波动）。
2. **观测空间残差单调下降**（1.1124 → 0.9734），**偏离观测的停止准则 B 从未触发**——与 REPORT21 的结论一致（修正不会把分析推离观测）。
3. 该路线整体仍**弱于"状态空间线性低秩 on z"（CELF 基 0.4732）与 GC(10000)+UV（0.4520）**，仅略优于 CELF 基（0.5247，−0.016）与 GC(10000)（0.5118）。
4. 与 REPORT17/20 的经验一致：**低秩修正在 1–2 步内即被"吃干"**；此参数化也不例外。
