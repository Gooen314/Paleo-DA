# REPORT 24：对 CELF 增益施加 GC 局地化（舒尔乘积）

**日期**：2026-09-13
**公式**：`xa = xf + (ρ ⊙ K_celf) · d`，`ρ = GC(haversine(grid, obs), cutoff, shape=1.0)`；无训练。
**口径**：MPI、TAS-only、无加权；`K_celf` 复用缓存 `Kc_celf_unw_mpi/`。

## 1. 结果（cutoff 扫描）

| cutoff (km) | train 1-550 | val 551-600 | **test 601-1100** |
|---|---|---|---|
| 5000 | 0.2561 | 0.2797 | 0.5578 |
| 7500 | 0.2505 | 0.2719 | 0.5427 |
| 10000 | 0.2474 | 0.2684 | 0.5354 |
| 15000 | 0.2438 | 0.2653 | 0.5287 |
| 20000 | 0.2417 | 0.2639 | 0.5260 |
| **∞（不锥化 = CELF）** | **0.2386** | **0.2633** | **0.5247** |

## 2. 结论
1. **对 CELF 增益做 GC 锥化是"有害"的**：锥化越强（cutoff 越小），RMSE 越差；**不锥化（纯 CELF）最优 0.5247**。
2. 即 **CELF 学到的增益已经包含了其所需的"局地化/正则化"结构**；外挂一个距离衰减 ρ 会**压低 CELF 学会使用的长程信息**，反而恶化。
3. 与早期结论一致：局地化的"脏活"（高秩远距压制）与 CELF 的学习目标存在**替代关系**——一旦增益是学出来的，"距离锥化"不再是正确先验。
4. 主方案 cut=10000（与 1–600 GC 最优半径对齐）为 **0.5354**，比 CELF 差 0.011。

（对照：GC(10000) AOEneKF 0.5118 ｜ CELF+学习型 Schur 调制 0.5065 ｜ 线性低秩 on z 0.4732 ｜ GC+UV 0.4520。）
