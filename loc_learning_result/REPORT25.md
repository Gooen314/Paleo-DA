# REPORT 25：新 ρ（0–B 段 GC、B 以外保留 1）对 CELF 增益的影响

**日期**：2026-09-13
**新 ρ**：
```
ρ(d) = GC(d; cut=B)   for d < B
ρ(d) = 1              for d ≥ B        （远距完全不锥化；d=B 处 0→1 跳变）
xa = xf + (ρ ⊙ K_celf) · d
```
无训练；MPI、TAS-only、无加权；`K_celf` 复用缓存。

## 1. 结果（边界扫描）

| B (km) | train 1-550 | val 551-600 | **test 601-1100** |
|---|---|---|---|
| 5000 | 0.2462 | 0.2738 | 0.5442 |
| **10000** | 0.2437 | 0.2669 | **0.5303** |
| 15000 | 0.2427 | 0.2648 | 0.5271 |
| 20000 | 0.2417 | 0.2639 | 0.5260 |
| —（不锥化 = CELF） | 0.2386 | 0.2633 | **0.5247** |

对照（cut=10000）：**全 GC 锥化 0.5354** ｜ 新 ρ(B=10000) **0.5303** ｜ CELF(不锥化) **0.5247**。

## 2. 结论
1. **新 ρ 仍是有害的**：B=10000 时 test **0.5303**，仍差于纯 CELF（0.5247，**+0.0056**）。
2. **但比"全 GC 锥化"温和**（0.5354 → 0.5303），符合预期——因为远距不再被压到 0；不过**中程（≈5000–10000 km，相关较强处）被压到近 0** 依然有损。
3. **随 B 增大（锥化范围缩小）逐步逼近 CELF**（20000 时 0.5260 ≈ 全锥化 20000 的 0.5260），趋势单调：**越是"不干预"，越接近最优**。
4. **总体判定**：对 **CELF 学到的增益做任何距离锥化都会恶化**——CELF 已经把"局地化/正则化"以数据驱动的方式学进了 ρ∘K0；外挂距离先验与该学习结构冲突。
   → 该方向可收束：**不应在 CELF 增益上叠加距离锥化**。
