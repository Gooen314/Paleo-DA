# REPORT 26：对 CELF 增益做标量 deflation

**日期**：2026-09-13
**公式**：`xa = xf + c · (K_celf d) = xf + c · z_C`，`c ∈ {1.0, 0.9, 0.8, 0.7, 0.6}`。
（`z_C` 为缓存增量；秒级，无训练。MPI、TAS-only、无加权。）

## 1. 结果

| c | train 1-550 | val 551-600 | **test 601-1100** |
|---|---|---|---|
| **1.0** | **0.2386** | **0.2633** | **0.5247** |
| 0.9 | 0.2394 | 0.2644 | 0.5269 |
| 0.8 | 0.2415 | 0.2673 | 0.5320 |
| 0.7 | 0.2449 | 0.2719 | 0.5400 |
| 0.6 | 0.2495 | 0.2781 | 0.5506 |

**val 最优 c = 1.0**（其 test = 0.5247，即无泄漏选参下也是 c=1）。

## 2. 结论
1. **deflation 单调有害**：c 越小（越把分析拉向先验均值 xf），train/val/test **全部变差**；**c=1 最优**。
2. 即 **CELF 的增量并不过度自信/过膨胀**——它没有"该缩而没缩"的问题。缩放的唯一效果是把分析拉向 **xf（test 0.6609，明显更差）**，所以必然恶化。
3. 因此 **CELF 劣于 GC(10000)（0.5247 vs 0.5118）不是"增益过大"造成的**；更可能源于前面分析的**非平稳迁移与缺少距离先验**（REPORT24/25 也表明：在 CELF 增益上外挂距离结构只会更差）。
4. 与 stage③ 的经验一致：**标量缩放增量无益**（那次 GC 基为 0.5030 vs 基线 0.5021）；本次 CELF 基同理。
