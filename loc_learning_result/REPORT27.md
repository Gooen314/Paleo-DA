# REPORT 27：对 CELF 增益做标量 inflation

**日期**：2026-09-13
**公式**：`xa = xf + c · (K_celf d) = xf + c · z_C`，`c ∈ {1.0, 1.1, 1.2, 1.3, 1.5}`。
（秒级、无训练；MPI、TAS-only、无加权。）

## 1. 结果

| c | train 1-550 | val 551-600 | **test 601-1100** |
|---|---|---|---|
| **1.0** | **0.2386** | **0.2633** | **0.5247** |
| 1.1 | 0.2392 | 0.2639 | 0.5254 |
| 1.2 | 0.2411 | 0.2662 | 0.5291 |
| 1.3 | 0.2443 | 0.2703 | 0.5356 |
| 1.5 | 0.2542 | 0.2832 | 0.5566 |

**val 最优 c = 1.0**（其 test = 0.5247）。

## 2. 结论（与 deflation 合并）

| c | 0.6 | 0.7 | 0.8 | 0.9 | **1.0** | 1.1 | 1.2 | 1.3 | 1.5 |
|---|---|---|---|---|---|---|---|---|---|
| test | 0.5506 | 0.5400 | 0.5320 | 0.5269 | **0.5247** | 0.5254 | 0.5291 | 0.5356 | 0.5566 |

1. **c=1 是全局最优**（两侧都变差），且曲线在 c≈0.9–1.1 附近较平。
2. ⇒ **CELF 增量的尺度已经最优**：既不过膨胀（inflation 无益），也不欠自信（deflation 无益）。
3. ⇒ **CELF 劣于 GC(10000)（0.5247 vs 0.5118）不是"尺度/膨胀"问题**，而是**结构与迁移**问题：
   - GC 用固定距离先验、不受训练/测试分布漂移影响；
   - CELF 的 ρ 由 1–550 步学习，盲测段（6–11 ka 深冰消）非平稳失配；外挂距离结构（REPORT24/25）或标量缩放（REPORT26/27）都救不回来。
4. 与 GC 侧的经验一致：1–600 的 inflation 扫描中 GC 的最优 infl 也是 **1.0**（越大越差）。
