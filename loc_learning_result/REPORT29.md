# REPORT 29：直接学习增益 K（而非乘性因子 ρ）的 CELF

**日期**：2026-09-13
**公式**：
```
特征 φ_j = [K0[:,j]/s_k, D_j/8000, coslat, spread_j/s_s]      # 4 通道（不含 GC）
输出 1 通道 g_θ(φ_j) ∈ R^n
K_mod[:,j] = K0[:,j] + s · g_θ(φ_j),     s = ks_scale（固定，≈0.0091）
xa = xf + Σ_j K_mod[:,j] · d_j
```
末层零初始化 ⇒ `g≡0` ⇒ 起点**精确等于 raw K0**（与 CELF 同起点）。
损失 CELF（cos-lat 状态 MSE）；train 1-550 / val 551-600 / test 601-1100；30 ep × 200 步；Adam lr 1e-4。

## 1. 结果

| 方案 | train 1-550 | val 551-600 | **test 601-1100** |
|---|---|---|---|
| CELF（学 ρ∘K0） | 0.2386 | 0.2633 | 0.5247 |
| **directK（学 K=K0+s·g）** | **0.2206** | **0.2449** | **0.5098** |
| GC(10000) | 0.2492 | 0.2664 | 0.5118 |
| xf（先验均值） | 0.2972 | 0.3427 | 0.6609 |
| （参照）CELF+UV | 0.1710 | 0.2190 | 0.4732 |
| （参照）GC+UV | — | — | 0.4520 |

## 2. 结论
1. **"直接学 K"全面优于"学 ρ∘K0"**：train −0.018、val −0.018、**test −0.015**（0.5247→0.5098）。⇒ 上一轮的判断成立：**乘性因子 `ρ∘K0` 把修正方向绑死在 K0 的列上，是表达力瓶颈**；改为加性残差增益（方向自由）即显著改善。
2. **首次有纯 CELF 族方案在盲测窗超过 GC(10000)**：0.5098 < 0.5118，且 train/val 也全面更好（不是靠牺牲验证换测试）。
3. 仍弱于带 UV 的路线：CELF+UV 0.4732、GC+UV 0.4520。但 **directK 是单阶段**，且可作为更好的基底（很可能与 UV 叠加后再提升——待后续验证）。
4. 本轮**没有出现 val/test 偏好冲突**（directK 三项全面改善），与 REPORT28（GC-aware）不同：说明"表达力提升"这一方向确实带来真实泛化增益，而"把 GC 结构硬塞进输入/目标"不是。
