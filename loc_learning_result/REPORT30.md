# REPORT 30：端到端低秩投影层（固定基）——阶段 0 诊断

**日期**：2026-09-13
**方案**：`δx = U_r diag(w) U_rᵀ (Σ_j K_mod[:,j] d_j)`，`U_r` 固定（气候/误差模态），`w` 可学习（初值 1），端到端训练。
**基座**：directK（test 0.5098）；口径：MPI、TAS-only、cos-lat 加权。
**诊断脚本**：`eof_proj_diag.py`（只读，含 directK 前向取 `δx_raw`）。

## 1. 结果

### D1 子空间天花板（oracle：`xa = xf + P_r(xt−xf)`，test 601–1100）
| r | 基 (a) 气候 EOF | 基 (b) 训练窗先验误差模态 |
|---|---|---|
| 5 | 0.5730 | 0.5462 |
| 10 | 0.5374 | 0.4630 |
| 20 | 0.4955 | 0.4039 |
| 30 | 0.4677 | 0.3824 |
| 50 | **0.4175** | **0.3534** |

⇒ 两个子空间**都有足够头寸**（r=50 时天花板 < 当前最优 0.4520）；(b) 明显更好。

### D2 后置硬投影（`w≡1`，不训练：`xa = xf + P_r δx_raw`）
| r | 基 (a) | 基 (b) |
|---|---|---|
| 5 | 0.6019 | 0.5793 |
| 20 | 0.5604 | 0.5209 |
| 50 | **0.5309** | **0.5099** |

对照：directK = **0.5098** ⇒ **硬投影 (a) 明显变差（+0.021）；(b) 基本中性（+0.0001）**。

### D3 能量与对齐
- `xt−xf` 在 r=50 子空间的能量占比：(a) 0.611 ｜ (b) 0.686；
- `δx_raw` 的能量占比：(a) 0.787 ｜ (b) 0.743 ⇒ **仍有 ~21–26% 的增量在子空间之外，且这部分有用**（去掉它 → D2 不变差即中性、变差即有害）；
- **主夹角**：stage④ 学到的 UV 基（20 维）与 (a) 的 cos 最高 0.914、与 **(b) 高达 0.978** ⇒ **学习型低秩已强烈对齐"误差模态"**。

## 2. 结论与建议

1. **固定基硬投影（w=1）不能带来收益**：(a) 有害（0.5309）、(b) 中性（0.5099）——与 REPORT24/25（GC 锥化）同一教训：**把固定结构硬套到学到的增益上会误删有效信号**。
2. **天花板不低但"因果可达"有限**：D1 的下限需用真值系数（oracle）；而增量由 d 驱动，D2 表明把当前增量投到子空间并不能改善。
3. **学习型 UV 已经是更优形态**：它与 (b) 高度对齐（cos≈0.98），且不是"投影"而是"秩-r 重建/修正"（可去噪、也可补充），我们在 CELF 基上已得 0.4732、GC 基 0.4520。
4. **对 E1（端到端固定基）的预判：提升空间小**——由于投影是中性/有害，且网络只能产出子空间内的增量，E1 大概率 ≈ directK（0.51），难以触及 0.4520。
5. **建议**：若要继续"端到端低秩"方向，应做 **E2（把 U,V 也设为可学习并与 U-Net 联合训练）**——保留端到端的好处、去掉固定子空间的束缚；E1 优先级低。
