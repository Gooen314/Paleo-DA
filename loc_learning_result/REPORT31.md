# REPORT 31：E2 端到端可学习低秩（directK 基座 + 联合训练）

**日期**：2026-09-21
**代码**：`train_e2_joint.py`、`eval_e2.py`、`make_fig_F56.py`
**上一步**：REPORT30（固定基硬投影诊断，结论：`w≡1` 的硬投影有害/中性）
**口径**：MPI 真值、TAS-only、cos-lat 加权；train 1–550 / val 551–600 / test 601–1100

---

## 1. 背景与动机

REPORT30 的诊断表明：把 U-Net 产出的增量**硬投影**到固定子空间（`w≡1`）**不会带来收益**——
气候 EOF 基下 test 0.5098 → 0.5309（变差），先验误差模态基下 0.5098 → 0.5099（中性）。

原因：增量里有 21–26% 的能量在 r=50 子空间之外，而这部分是**有用的**（去掉并不改善）。

因此本方案（**E2**）放弃"固定基 + 硬投影"，改为：
- 保留低秩修正的形式，但 **`U,V` 是自由可学习参数**（不锁死任何基）；
- 把低秩修正**放进 PyTorch 计算图**，与 U-Net **联合端到端训练**（"训练即部署"）。

目标：验证"端到端"能否超过两阶段 `CELF+UV`（test 0.4732）与当前最优 `GC(10000)+UV`（test 0.4520）。

## 2. 数据与记号

数据目录：`/data1/wbgu/agentdata/loc_learning/pairs_unw_mpi/t####.npz`（每时刻一帧，共 1100 帧）。

| 量 | 含义 | 维度 |
|---|---|---|
| `K0_t` | 无局地化、无 inflation 的样本增益 `C_xh (C_hh + R)⁻¹` | `n × M_t` |
| `d_t`（innov） | 新息 `y_t − H xf_t` | `M_t` |
| `xf_t` | 类比集合均值（先验均值） | `n` |
| `xᵗ_t`（xt） | 真值（MPI） | `n` |
| `oi_t` | 当步活跃代理在 1276 代理表中的索引 | `M_t` |
| `spread_t` | 当步先验离散度 | `M_t` |

- 状态维数 `n = 6144`（TAS 网格 64×96，可展平为 6144）；
- 代理总数 `1276`；当步活跃观测数 `M_t` 逐时变化，约 388–720；
- `D`：`1276 × 6144` 的"代理点→格点"球面距离矩阵（`haversine`）；
- 尺度：`ks_scale ≈ 0.00911`（`mean(|K0|)` 的跨时刻均值）、`spread_scale ≈ 0.3204`；
- 低秩：`r ∈ {5, 20}`。

## 3. 方法（逐步公式）

### 3.1 逐观测输入特征（4×64×96 图）

对第 `j` 个活跃观测（`j = 1..M_t`）构造一张特征图 `φ_j`：

```
ch0 = K0_t[:, j] / ks_scale            # 该观测的 raw 增益列（归一化）
ch1 = D[oi_t[j]] / 8000                # 观测 j 到各格点的球面距离场（km/8000）
ch2 = cos(lat)                          # 纬度权重场（64×96）
ch3 = spread_t[j] / spread_scale        # 该观测的先验离散度（归一化）

φ_j = stack(ch0, ch1, ch2, ch3)  ∈ R^{4×64×96}
```
- 所有特征**不含真值**（`K0, D, coslat, spread` 均为先验/几何量）⇒ 无泄漏。

### 3.2 U-Net 前向（逐观测）

```
g_θ(φ_j) ∈ R^{6144}
```
- `θ` 为 U-Net 参数（结构见 `results/CELF结构.md`；约 6.5×10⁵ 参数）；
- 末层 `Conv2d(·,1,1)` **零初始化** ⇒ 从零开始训练时 `g≡0`；
- 本实验 **warm-start**：`θ ← results/loc_celf_directK.pt`（已训练好的 directK 网络）。

### 3.3 增益合成

```
K_mod[:, j] = K0_t[:, j] + s · g_θ(φ_j),      s = ks_scale（固定常数）
```
- 网络输出 `g` 是 O(1) 量级，乘固定尺度 `s` 后与增益同量级（`K0 ~ 1e-2`）；
- 零初始化/warm-start 使其起点就是 raw/directK 的增益。

### 3.4 未滤波的原始增量

```
dx_raw = Σ_{j=1}^{M_t} K_mod[:, j] · d_t[j]   ∈ R^n
```
实现（在 `(M_t, n)` 布局上）：
```python
dx_raw = ((K0.T + ks_scale * field) * d[:, None]).sum(dim=0)
```
- 注意这是 `K_mod` 的**逐观测列**乘对应新息分量后求和，等价于 `K_mod @ d`；
- 它对应"若不施加任何低秩修正时的分析增量"。

### 3.5 可学习的低秩修正

```
a    = Vᵀ dx_raw                  ∈ R^r          # 潜系数（把增量投到 r 维潜空间）
corr = U a                        ∈ R^n          # 用 U 升维回状态空间
U, V ∈ R^{n×r}                    （自由参数，小随机初值 ~1e-3）
```
- 修正量为**秩 ≤ r** 的状态空间向量；
- `corr` 与 `dx_raw` 同量级地叠加在增量上。

### 3.6 最终分析场

```
xa = xf + dx_raw + corr
   = xf + (I + U Vᵀ) dx_raw
```
- 有效算子为 `ρ = I + U Vᵀ`：**`n×n` 稠密矩阵，但秩 ≤ r**（对角为 1，非对角为低秩修正）；
- **实现上从不显式构造 `UVᵀ`**，而是分两步计算（见 3.5），复杂度 `O(nr)` 而非 `O(n²)`；
- 起点（`U,V` 小随机）时 `corr≈0` ⇒ `xa ≈ xf + dx_raw`，即**起点等于 directK 分析**（test 0.5098）。

## 4. 训练目标与优化

### 4.1 损失函数（逐时刻 = cos-lat 加权 MSE）

```
loss_t = mean_j [ W_j · (xa_t,j − xᵗ_t,j)² ],     W = cos(lat) / mean(cos(lat))
```
**等价性推导**：设状态有 `n` 个格点，`w_j := cos(lat_j) / Σ_k cos(lat_k)`（归一化权重，`Σ_j w_j = 1`）。则

```
mean_j [ W_j · e_j² ] = (1/n) Σ_j (cos lat_j / mean(cos lat)) · e_j²
                     = (1/n) Σ_j (cos lat_j / (Σ_k cos lat_k / n)) · e_j²
                     = Σ_j [cos lat_j / Σ_k cos lat_k] · e_j²
                     = Σ_j w_j e_j²
```
即训练损失**恰好等于** `RMSE_t²`（用归一化 cos-lat 权重），与评估口径一致。

### 4.2 优化设置

```
优化器：Adam，两个参数组
        - U-Net 参数 θ            → lr = 1e-4
        - 低秩参数 U, V            → lr = 1e-3
梯度：  clip_grad_norm_([θ, U, V], max_norm = 5.0)
调度：  ReduceLROnPlateau(factor=0.5, patience=3)，监控 val 的加权 MSE
轮数：  30 epochs × 200 随机训练步 / epoch
保存：  每个 epoch 末在 val(551–600) 全量评估，保存 val 最优的 (θ, U, V)
初始化：θ ← directK checkpoint（热启动）；U, V ~ N(0, 1e-3²)（⇒ corr≈0）
```

> 说明：`U,V` 若零初始化会落在**鞍点**（梯度恒为 0，学不动），因此采用**小随机初始化**——这是本项目此前的经验教训。

## 5. 评估口径（与训练日志数值的区别）

评估脚本 `eval_e2.py` 对全部 1100 步计算：

```
逐时误差： e_t = xa_t − xᵗ_t
逐时 RMSE：RMSE_t = sqrt( Σ_j w_j · (e_t,j)² )     ,  w_j = cos(lat_j)/Σ_k cos(lat_k)
窗口值：   train = mean_{t=1..550} RMSE_t
           val   = mean_{t=551..600} RMSE_t
           test  = mean_{t=601..1100} RMSE_t
```

**两个口径的差别（务必区分）**：
| 来源 | 量 | 定义 |
|---|---|---|
| 训练日志里打印的 `val`（如 0.04977） | **加权 MSE** | `mean_t [ Σ_j w_j e² ]` |
| 本报告表格里的 `val`（如 0.2206） | **逐时 RMSE 的均值** | `mean_t sqrt( Σ_j w_j e² )` |

两者关系：`sqrt(0.04977) ≈ 0.2231`（≈ 报告中的 0.2206，差异来自 `sqrt(mean) ≠ mean(sqrt)`，即 Jensen 不等式造成的微小差别）。**本报告一律采用"逐时 RMSE 的均值"，与项目其它报告（REPORT 系列）保持一致。**

## 6. 参数形状 `n×r` 与有效算子 `n×n`（重要澄清）

```
U ∈ R^{n×r},  V ∈ R^{n×r}        # 参数是两张"瘦"矩阵
UVᵀ ∈ R^{n×n}                    # 乘积是 n×n（6144×6144），但秩 ≤ r
ρ = I + U Vᵀ ∈ R^{n×n}           # 有效算子：对角为 1 的 n×n 稠密矩阵（99.9% 作用来自非对角低秩部分）
```
- **参数规模**：`2 n r`（r=20 ⇒ 245,760 个），而非 `n²`（37,748,736 个）；
- **计算方式**：先 `a = Vᵀ dx_raw`（`O(nr)`），再 `corr = U a`（`O(nr)`），从不构造 `UVᵀ`；
- 因此"**学一个 n×n 矩阵**"的直觉要修正为：**用两层瘦矩阵表示一个秩 ≤ r 的 n×n 稠密算子**；
- 这正是此前一贯的"状态空间低秩算子"（stage③/④、REPORT17/20/21）所使用**完全相同的参数化**。

## 9. 结论与局限

1. **E2 相对其基座有增益**：directK test `0.5098 → 0.4797`（−0.030）；r=20 优于 r=5（−0.011）。
2. **未超过"两阶段 CELF+UV"（0.4732）**：提案的核心假设"端到端 > 两阶段"在本配置下**未获证实**。
   - **原因**：两阶段 UV 是在**冻结增量**上求解**线性最小二乘**（凸问题，易达近似全局最优）；
     而 E2 的联合训练是**非凸**、`θ` 与 `U,V` 相互耦合，其 val 加权 MSE（0.04977 → RMSE≈0.223）也略差于两阶段的 val（0.2190）。
3. **距当前最优 `GC(10000)+UV`（0.4520）仍差 0.028**。
4. **局限**：
   - 未做多种子/多随机初值的稳定性统计；
   - 未做超参搜索（`lr_uv`、`r`、训练轮数）；
   - 未与"两阶段初始化 + 端到端微调"（E2′）对照。

### 下一步建议
- **E2′：两阶段初始化 + 端到端微调**——先在冻结增量上用线性最小二乘解出 `U₀,V₀`，再以其为初值联合微调；兼顾"凸解的质量"与"端到端的自适应"。
- **换基座**：在 `GC(10000)` 基座上做同样的联合微调（`GC+UV` 已是 0.4520，有望再下探）。
