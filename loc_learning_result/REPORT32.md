- **GC 族 + UV**：`uvloc_mpi.npz`（Loc8000+UV，test **0.4546**；与 `GC(10000)+UV` 0.4520 同族，U,V 此前未单独落盘）
- **E2**：`loc_celf_e2r20.pt`（directK + 联合低秩，test **0.4797**）

**代数基线**（两方案共通）：
```
K_eff[:,j] = K[:,j] + U (Vᵀ K[:,j])      ⇔   K_eff = (I + U Vᵀ) K
xa = xf + (I+UVᵀ) K d
```

## 1. 诊断结果

### D1 修正幅度（**O(1)，不是小扰动**）
| 指标 | GC 族+UV | E2 |
|---|---|---|
| `‖U(Vᵀz)‖ / ‖z‖`（增量空间，均值） | **1.05** (q10 0.74, q90 1.42) | **2.15** (q10 1.51, q90 2.96) |
| `‖U(Vᵀk)‖ / ‖k‖`（逐增益列，均值） | 0.93 | 1.33 |

⇒ UV 把增量**整体放大/重构**（E2 约 ×2），完全是"重构"而非"微调"。

### D2 基的空间归属（余弦主夹角）
| 对比 | 前几个主夹角 |
|---|---|
| GC 族 `U` vs **先验误差模态** | 0.972, 0.955, 0.953, 0.945, ...（第 10 个仍 0.795） |
| E2 `U` vs **先验误差模态** | 0.985, 0.982, 0.979, 0.970, ...（第 10 个 0.926） |
| GC 族 `U` vs 气候 EOF | 0.857, 0.820, 0.770, ... |
| E2 `U` vs 气候 EOF | 0.947, 0.883, 0.849, ... |
| `U` 落在 `span(K0)`（集合张成）内的能量比 | 0.726（两方案一致） |

⇒ **`U` 高度对齐"跨模式先验误差"的主方向**；约 **73% 在集合张成内、27% 在其外**（少量"信息重路由"）。

### D3 跨方案比较
| 对比 | 主夹角 |
|---|---|
| **`U`(GC族) vs `U`(E2)** | **0.986, 0.979, 0.968, 0.956, ...**（第 10 个 0.808） |
| `V`(GC族) vs `V`(E2) | 0.687, 0.641, 0.617, ... |
| `U` vs `V`（同方案内） | 0.665（GC族）/ 0.436（E2） |
| `U` 的奇异值（前 3） | GC族 2.60/2.17/1.72 ；E2 4.18/3.75/2.64 |

⇒ **两个方案的"修正方向 `U`"几乎相同**（是**数据决定、与基座无关**的"规范方向"）；**编码器 `V` 随基座而变**；`U≠V`（算子非对称）；E2 的修正强度更大。

### D4 "逐模态缩放" vs "跨模态混合"（在误差模态基下）
```
C = (QᵀU)(VᵀQ) ,  Q = 前 20 个误差模态；offdiag 能量占比：
    GC 族 0.853 ｜ E2 0.681
```
⇒ 修正是**跨模态混合主导**（85%/68%），**不是**逐模态缩放；GC 族对角项多为收缩（0.87/0.41/0.44…），E2 对角项多为放大（1.9/2.0…）。

### D5 观测空间残差（UV 修正前 → 后，均值）
```
GC 族: 25.41 → 23.98  (ratio 0.945)
E2   : 25.27 → 23.79  (ratio 0.944)
```
⇒ UV 使分析**更贴近观测**（残差降 5.6%），无"偏离观测"的系统性风险。

## 2. 机制画像（诊断驱动的结论）

> **UV ≈ "把增量按编码器 `V` 读出、再沿"跨模式误差主方向 `U`"写回"的、O(1) 量级的低秩重构算子。**
> - 它**不是**去噪/投影（D1 幅度 O(1)、D4 以混合为主）；
> - 它的"修正方向"是**跨模式结构误差的主子空间**（D2，cos≈0.97–0.99），且**跨方案几乎相同**（D3，cos≈0.99）——即 `U` 是**数据决定的规范基**，与基座增益无关；
> - 它主要在"集合张成之外"做有限的重路由（27% 能量在 `span(K0)` 外），并把分析拉向观测（D5）。

**给 UV 背书的动机（按证据强度排序）**：
1. **M1 低秩结构误差修正（最强，直接证据 D2/D3）**：UV 的 `U` 就是跨模式误差的主方向；这正是"我们缺的修正"所在。
2. **M3 信息重路由（中，D2 的 27%）**：能把观测信息投到集合张成 `span(K0)` 之外，突破 K=100 的秩限制。
3. **M2 交叉协方差 `P Hᵀ` 的秩-r 校正（理论等价）**：UV 只左乘 Kalman 增益的分子（`P Hᵀ`），分母不变——即"**状态-观测交叉协方差的低秩状态空间修正**"。
4. **M4 增益去噪（弱，D1/D4 反驳）**：UV 并非小扰动去噪，而是幅度可观的跨模态重构。

## 3. 由诊断直接推出的新方案（待你判断）

| # | 方案 | 公式 | 诊断依据 |
|---|---|---|---|
| **N1** | **固定物理基 `U` + 学系数** | `U = 训练窗先验误差模态（前 r）` 固定；`xa = xb + z + U c`，`c = Wᵀz`（学 `W∈R^{n×r}`）或 `c = φ_θ(z)` | D3：`U` 跨方案几乎相同 ⇒ **不需要学 `U`**，固定即可；参数量从 2nr 降到 nr |
| **N2** | **N1 的对角对照** | 同上，但只学逐模态缩放（`W` 与 `U` 同基） | D4 预测：**会明显变差**（混合主导），可作机制对照 |
| **N3** | **自洽的秩-r PSD 协方差修正** | `P' = P + U S Uᵀ`，Woodbury 重算 `K' = P'Hᵀ(HP'Hᵀ+R)⁻¹` | M2：把"左乘"换成"真的改协方差"，物理自洽 |
| **N4** | **只改交叉协方差 `P Hᵀ`（显式）** | `K_eff = K + U C`，`C∈R^{r×M}` 逐步直接学（去掉 `C=VᵀK` 的耦合） | M2：现有 UV 的系数被 `VᵀK` 绑死，N4 解绑 |

**判据（你给的）**：只要 **test > 基线 `GC(10000)` = 0.5118 的改善方向**（即"不劣于基线且能打平或更好"）；允许比现有最优（0.4520）差。

> 建议先做 **N1**（最省参、最能验证"D3 的规范基"结论）：若 N1 ≈ E2（0.4797），则证明"`U` 无需学习、物理基即可"，可以直接用**训练窗误差模态**给出可解释的 UV；若 N1 明显变差，则说明 `U` 的学习仍有价值（与 D3 的结论矛盾，值得深究）。
