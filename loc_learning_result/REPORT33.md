# REPORT 33：N1——固定"物理基 U"、只学编码器（验证 D3 的规范基结论）

**日期**：2026-09-21
**代码**：`train_n1_fixedU.py`、`eval_n1.py`、`make_fig_F58.py`
**依据**：REPORT32 的 D3 诊断——`U`(GC 族+UV) 与 `U`(E2) 的主夹角 cos ≈ **0.986/0.979/0.968…**，即"修正方向"是**数据决定、与基座无关**的规范方向。

## 1. 方案
```
U 固定： Q_r = 训练窗先验误差 (xf − xᵗ) 的 cos-lat 加权 SVD 前 r 个模态   （仅 1–550，无泄漏）
学：     编码器 W ∈ R^{n×r}（小随机初值）+ U-Net 参数 θ（warm-start 自 directK）
xa = xf + dx_raw + Q_r (Wᵀ dx_raw)
损失/协议：CELF（cos-lat 加权 MSE）；train 1-550 / val 551-600 / test 601-1100；30 ep × 200 步
```
与 E2 的唯一区别：E2 里 `U` 是自由参数，N1 里 `U` 换成固定的 `Q_r`（参数量 `2nr → nr`，减半）。

## 2. 结果（cos-lat 加权 TAS RMSE）

| 方案 | 参数 | train | val | **test** |
|---|---|---|---|---|
| directK（基座） | θ | 0.2206 | 0.2449 | 0.5098 |
| E2 r=20（学 U,V） | θ+2nr | 0.1741 | 0.2206 | **0.4797** |
| **N1 r=20（固定 U=Q_r，只学 W）** | θ+nr | 0.1726 | 0.2259 | **0.4809** |
| **GC(10000)（用户指定基线）** | — | 0.2492 | 0.2664 | **0.5118** |
| CELF+UV | — | 0.1710 | 0.2190 | 0.4732 |
| GC(10000)+UV | — | — | — | 0.4520 |

## 3. 结论
1. **固定 `U` 不损失性能**：N1 **0.4809** vs E2 **0.4797**，差 **0.0012**（运行内波动量级）——
   ⇒ **D3 的"修正方向是数据决定的规范基"结论得到验证：`U` 不需要学。**
2. **N1 优于用户指定基线 GC(10000)（0.5118）**，改善 **−0.031**（相对 −6.0%）。
3. **N1 的优势**：
   - 参数量减半（`nr` vs `2nr`）；
   - **可解释**：`Q_r` 是"我们真正要修正的误差"的主空间结构（训练窗统计量），`U` 不再是黑箱；
   - 与 E2 数值等价 ⇒ 可用更少参数讲清"修正沿误差主方向进行"的物理故事。
4. **局限**：仍弱于两阶段 `CELF+UV`(0.4732) 与 `GC(10000)+UV`(0.4520)；`Q_r` 取自训练窗，其向盲测窗的迁移性靠"u 跨方案一致 + N1≈E2"间接佐证（若换 r 或换训练窗需重算基）。

## 4. 物理/数学表述（可直接引用）
```
UV/N1 的作用：K_eff[:,j] = K[:,j] + Q_r (Wᵀ K[:,j])
   = "用编码器 W 读出该观测增益列的低维坐标，再沿跨模式误差主方向 Q_r 写回修正"
等价地：对 Kalman 增益的分子（状态-观测交叉协方差 P Hᵀ）做秩-r 状态空间修正。
```
