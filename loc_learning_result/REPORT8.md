# REPORT 8：把算子放在 xb 上（P1）—— 未通过，熔断

**日期**：2026-09-13
**目标**：检验"把低秩算子作用在**先验均值 xb**（而非增量）上"是否能优于 AOEnKF_Opt（0.5021）。
**基础**：raw z0（无 GC、无 inflation），从头起步。
**结论**：**P1 未通过，按约定熔断，不进入 P2（动态）/P3（叠加）。**

---

## 1. 方案

```
基础:  xa_raw = xb + K0 d          # raw 增益，无 loc / 无 inflation
corr = U (V^T xb)                  # 先验修正（秩 r，静态）

(a) 不自洽版:  xa = xa_raw + corr
(c) 自洽版:    xb' = xb + corr
               d'  = d - H_obs corr
               xa  = xa_raw + corr - K0 (H_obs corr)
损失: CELF = Σ w_j (xa-xt)^2 / Σ w_j + λ(||U||²+||V||²)
划分: 1-550 / 551-600 / 601-1100
```

**观测算子 H**：项目没有物化的 H（`Hx_*.mat` 是预计算）。本工作重建为
- `build_H.py`：规则网格（96×3.75° lon，64×2.8125° lat）双线性 + 末列最近邻外推；
- `build_H2.py`：在每个代理的局部邻域上做最小二乘拟合（用 pool 的 tas→hx 配对）；
- 验证：`H_refined @ tas` 对 `hx` 的 RMSE = **4.5e-7**（hx std = 7.98），即精确恢复。

## 3. 门 G2：失败

- (a) 最优 0.5556 > 0.5021；(c) 最优 0.5419 > 0.5021；
- 二者相对 raw 有改善（0.5805 → 0.55/0.54），但**远未达到门限**；
- 按约定：**熔断**，不进入 P2/P3。

## 4. 诊断

1. **显著的非平稳性**：P1 的 val RMSE ≈ 0.28，而 test ≈ 0.54–0.66；先验误差从训练窗到评估窗近乎翻倍（P0 诊断：train 0.296 → test 0.657）。
2. **静态 xb 修正学不迁移**：训练窗上学到的"先验偏差修正"在评估窗失效；λ=0 时明显过拟合，λ=1e-3 时虽稳定但仍达不到门限。
3. **与"修增量"的本质差别**：增量 `z = K0 d` 由**当前时刻的观测/集合**决定，随流场自适应；而 `corr = U(V^T xb)` 是 xb 的全局静态函数，无法跟随评估窗的气候态漂移。这解释了为什么同样的低秩形式在增量上有效（0.4724）、在 xb 上失败（0.54+）。
