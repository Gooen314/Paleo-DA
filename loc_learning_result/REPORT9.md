# REPORT 9：xb 算子路线收尾（P1-c 通过降门槛 · P2/P3 无效）

**日期**：2026-09-13
**背景**：P1（把算子放在 xb 上）原定门限"test < 0.5021（AOEnKF_Opt）"未过。
按用户决定**降低门槛：允许 (c) 方案 test < 0.55 通过**（(a) 最优 0.5556 仍不过）。
随后继续执行 P2（动态 xb 算子）与 P3（与增量算子叠加）。

---

## 1. 结果汇总（test 601–1100 TAS RMSE）

| 方案 | 形式 | test | 备注 |
|---|---|---|---|

| 参考：GC+PQ / CELF+PQ | — | 0.4724 / 0.4759 | 现有最好 |

## 2. 结论

1. **降门槛后 P1-c 通过**（0.5419 < 0.55），但需明确：它**仍未超过 AOEnKF_Opt（0.5021）**，更远逊于现有最好（0.4724/0.4759）。
2. **P2 动态化失败**：训练 0.222 / 验证 0.266 / 测试 0.654 —— 典型过拟合；用网络生成 xb 修正场（~65 万参数、仅 550 训练步）无法泛化到评估窗。
3. **P3 叠加无增益**：0.5403 与 P1-c 的 0.5419 持平（差异在噪声内）；增大秩（r=20, λ=0）反而过拟合到 0.7963。
4. **根因（与 P0/P1 一致）**：先验偏差强非平稳（训练/验证 ~0.27–0.30，测试 ~0.54–0.66），任何以 `xb` 为输入的静态（或动态但样本不足的）修正都学不到可迁移的结构；而增量 `z = K0 d` 由当前观测/集合自适应，故同样的低秩形式在增量上有效。
