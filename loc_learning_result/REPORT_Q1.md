## 0. 约定（照文档 0.1–0.4）
- 真值 MPI；池 `{trace,had_g,had_h}`；TAS n=6144。
- 误差定义：`e = truth − xa0`（真值减基座分析）；基座分析 `xa0 = xb + z`。
- 主指标：加权 MSE `J = mean‖e‖²_D`（`w_i=cos(lat_i)/Σcos`）；同时给平均 RMSE。
- 划分：固定评估段 601–1100（**属探索性再分析**）；内部连续折 F1 训1–250/验251–350、F2 训1–350/验351–450、F3 训1–450/验451–550；历史协议 训1–550/验551–600。选参只由验证段完成。
- `Q` 用文档规范构造：`D^(1/2)F = LΣRᵀ, Q = D^(-1/2)L_r`（n×r，`QᵀDQ=I`）。

## 2. Q3-01 Q 构造审计 —— 发现历史实现与规范不一致（须命名区分）
| r | 正交误差（doc / his） | 两子空间 min\|cos\| | 先验误差能量捕获（doc / his） |
|---|---|---|---|
| 5 | 1.6e-15 / 6.7e-16 | 0.9575 | **0.601 / 0.574** |
| 10 | 1.6e-15 / 6.7e-16 | 0.9480 | **0.707 / 0.681** |
| 20 | 1.6e-15 / 1.1e-15 | 0.9383 | **0.801 / 0.775** |
| 50 | 1.6e-15 / 6.7e-16 | 0.9091 | **0.902 / 0.880** |

- 两者都满足 `QᵀDQ=I`，但**张成的子空间不同**（cos 0.91–0.96），且**规范式一致更好**。
- 历史 `build_Q`（`SVD(加权误差) → 对 D^(1/2)V_r 做 QR 再除 D^(1/2)`）等价于取 `span(U_r)` 的 D-正交基，而非规范的 `D^(-1/2)span(U_r)`。
- **结论**：历史 N1/N4/S1 用的是"历史口径 Q"，应明确命名；本 Q1 全部使用**规范 Q**。若后续要复现历史数字，需用历史口径（两者不可混称）。

| 不修正 | 0.3690 | 0.2921 |
| 常数偏差 `mu_e`（训练窗） | **0.4077（更差 −10.5%）** | **0.3234（更差 −10.7%）** |
| 增量回归 r=5（中心化） | 0.3517 (−4.7%) | 0.2818 (−3.5%) |
| 增量回归 r=20（中心化） | 0.3412 (−7.5%) | **0.2483 (−15.0%)** |
| 增量回归 r=50（中心化） | **0.3295 (−10.7%)** | **0.2473 (−15.4%)** |
| 同 r 无截距（历史式） | 0.3298 | 0.2531 |

**验证段同样改善**：raw 0.0903→0.0641、GC 0.0718→0.0519（r=50）。

**系数（Q1-04，GC r=20，test 逐模态）**：k=0 技能 0.529、相关 +0.48；其余模态技能多为**负**（−0.2…−13）但相关多为**正**（+0.08…+0.55）。
→ 逐模态预测"**相关存在、幅度/校准差**"（技能比受训练窗分母与非平稳影响）；**聚合 MSE 的改善主要来自正则收缩**，不是单模态强预测。此项须在报告里如实说明。

## 5. Q1-05 背景对照（关键负对照）
- **含时间多项式（t, t²）的背景模型在固定评估段爆炸**（raw test 1.02、GC 0.90）：外推失败，印证文档"避免难约束外推"的告诫。**该配置不用于结论**。
- **物理协变量背景**（常数 + 先验全球均温 + 观测数，仅训练段拟合后冻结）：

| 方案（MSE） | raw train/val/test | GC train/val/test |
|---|---|---|
| 基座 | 0.0745/0.0903/0.3690 | 0.0647/0.0718/0.2921 |
| 背景模型 `ê_g` | 0.0630/0.0826/0.3635 | 0.0544/0.0713/**0.3126（更差）** |
| 背景 + 增量残差 | 0.0495/0.0737/0.3462 | 0.0419/0.0630/0.2908 |

→ **可用的背景协变量不能解释增量的技能**：GC 上加背景反而**伤害**评估段（0.3126>0.2921）；"背景+增量"（0.2908）也**远不如纯增量回归（0.2483）**。故 Q1 的技能**不是**来自"全球均温/观测数"这类背景关系。

- 误差**慢变分量主导**（GC σ=10：慢 0.2218、快 0.0632，合计 0.2921；raw 慢 0.2818、快 0.0807）。
- 慢分量可预测：GC σ=5 慢基座 0.2290 → 慢修正 0.1994；raw 0.2894→0.2451。

## 10. 结论（Q1 完成判据）
> **是**：基座分析之后**确实存在可由分析增量预测的剩余误差**，且该技能
> ① **超出常数平均偏差**（训练窗 `mu_e` 在评估段反而使 MSE 恶化 10%）；
> ② **超出可用的背景协变量**（加"全球均温+观测数"背景在 GC 上伤害评估段；背景+增量 0.2908 ≪ 纯增量 0.2483）；
> ③ **不能被共同趋势解释**（块错配与滞后移位都显著更差）；
> ④ **在验证段与固定评估段一致**，连续时间块 bootstrap 的成对改善 CI 不含 0（GC test Δ=0.0439，91% 时刻为正）；
> ⑤ **增量 `z` 是最可迁移的输入**（`z ≫ xa0 ≫ xb`）。

**如实记录的限制**
1. 601–1100 **已被多轮查看**，本条为探索性再分析，不宣称全新独立盲测。
2. 逐模态系数技能多为负（相关为正、幅度失配）⇒ 聚合改善**依赖正则收缩**，"每个模态都可预测"**不被支持**。
3. 背景对照仅覆盖有限协变量（常数/全球均温/观测数）；时间趋势型背景**不可用**（外推爆炸），因此结论限定为"超出这些背景"。
4. 误差以**慢变分量为主**，快变分量的可预测性未单独证明。
5. 主实验用**规范 Q**；历史 `build_Q` 口径不同（§2），历史数字不能与本报告逐项拼接。
