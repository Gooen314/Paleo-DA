4. **全状态读出 M5 再改善**（0.2557）；**RRR（M6）最好**（0.2520）。
5. **Q4-08 简约判据**：M6 是闭式、无训练、参数 n·r（秩 r 约束）⇒ 在同等（甚至更优）性能下**优先 M6**。

## 4. Q4-10 最终公式与叙述

**最终推荐（MPI 场景、GC 基座）**：
```
xa = xa_GC + mu_e + β · B_r (z_GC − mu_z)

其中：
  z_GC = xa_GC − xb            （真实串行 EnSRF 的 GC 增量）
  mu_e, mu_z ：训练段（1–550）误差均值场 / 增量均值场
  B_r = D^(−1/2) [M]_r A^(−1/2)  （正则降秩回归，闭式）
        A = Z_c Z_cᵀ + ηI ,  Z_c = Z − mu_z 1ᵀ
        M = D^(1/2) E_c Z_cᵀ A^(−1/2) ,  E_c = E − mu_e 1ᵀ ,  [M]_r = 最佳秩-r 截断
        η = λ · tr(Z_c Z_cᵀ)/n ，λ=10（内部折选定）；r=50
  β ≈ 0.865 （校准集 551–600 闭式估计）
  等价：Q_predictable = D^(−1/2)L_r ，Wᵀ = Σ_r R_rᵀ A^(−1/2) ，B_r = Q_predictable Wᵀ
```
**性能**：test 601–1100 均值 RMSE **0.4531**（β=1 时 0.4591），**≈ 历史两阶段学习型 `GC(10000)+UV` 的 0.4520**，且**优于** CELF+UV(0.4732)、N1(0.4809)、E2(0.4797)、directK(0.5098)、GC 基座(0.5118)。

**科学叙述（与 Q1–Q3 闭环）**
> 基座同化之后，剩余误差中存在**超出常数与背景的、可由分析增量预测的部分**（Q1）；GC 通过**同时降低子空间外误差与改善可预测条件**放大低秩修正的价值，其在 raw 基座上的收益**可归因于消除有限集合采样噪声（恢复 98.6%）**（Q2/Q2-09）；该修正可写成**"按可预测性选择输出方向 + 跨模态混合 + 状态空间读出"**的统计映射，净改善集中在最低阶误差模态（Q3）；收束为**闭式正则降秩回归 + 一个全局幅度校准 β**，其性能已与网络/自由 UV 相当，但**无需训练、参数量更小、含参更透明**（Q4）。

**限制（如实记录）**
1. 评估段 601–1100 已被多轮查看，属**探索性再分析**；内部折才是严格选参依据。
2. 真值固定为 MPI；TRACE/HAD 场景已证不成立（REPORT12–14），本收束**不外推到其他真值**。
3. M3–M5 用 `Q_prior`；Q3 显示 `Q_analysis` 更优 ⇒ 这些数字偏保守，但结论（混合/全读出/降秩回归必要）不受影响。
4. `β` 为**全局标量**；逐模态 β_k 未作主方案。
5. GC 的采样噪声归因限于**候选池/训练窗**口径（Q2-09 §限制）。
