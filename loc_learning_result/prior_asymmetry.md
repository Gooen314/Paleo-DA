# 诊断：为什么 truth=MPI 与 truth=TRACE 的先验组成如此不对称

**日期**：2026-09-13　脚本：`diag_prior_asym.py`

## 1. 模式间代理空间距离（|Hx_m1 − Hx_m2|，1276 代理 × t=1..1100 平均）

```
trace vs had_g : 0.7233        had_g vs had_h : 0.3428   ← 近乎重复
trace vs had_h : 0.7130        had_g vs mpi   : 0.7508
trace vs mpi   : 0.7766        had_h vs mpi   : 0.7596
```

**had_g 与 had_h 几乎是同一模式**（0.343，其他对 0.71–0.78）。

## 2. 先验组成（F34，K=100 类比成员来自哪个模式）

| 真值 | 池 | 组成 |
|---|---|---|
| MPI | trace, had_g, had_h | **trace 59%** / had_g 21% / had_h 20% |
| TRACE | had_g, had_h, mpi | had_g 38% / had_h 42% / **mpi 20%** |

## 3. 机制：选择是"最近邻"（极值序统计）规则

AOEnKF 每个时刻在约 1500 个候选里取 **距离最小的 100 个**，因此**由距离分布的"下尾"决定，而非均值**。微小下尾差异会被放大成巨大的组成差异。

**各模式到真值观测的距离（下尾）**

```
truth=mpi   (y 均值 -0.33):  trace min 0.721 p0.5 0.823 p1 0.841 | 均值距离 1.389(最差)
                             had_g min 0.730 p0.5 0.829 p1 0.846 | 均值距离 1.164
                             had_h min 0.723 p0.5 0.829 p1 0.846 | 均值距离 1.170
truth=trace (y 均值 -0.47):  had_g min 0.896 p1 0.959 | mpi min 0.885 p1 0.980
                             had_h min 0.887 p1 0.959
单点最优次数:  truth=mpi → trace 910/1100 (83%)；truth=trace → had_g 417 / mpi 364 / had_h 319
```

- **truth=mpi**：trace 在**每一个分位数上都略优**（p0.5 0.823 vs 0.829；p1 0.841 vs 0.846）→ 最近邻选择放大为 **trace 59% / 单点最优 83%**。注意 trace 的**平均距离反而最差**（1.389 vs 1.164）——纯粹是**下尾效应**。
- **truth=trace**：had_g≈had_h（近乎重复），在 p1 上（0.959）略优于 mpi（0.980）→ **had 对合计 80%**，mpi 20%。

## 4. 结论

不对称的根源是两条叠加：

1. **had_g 与 had_h 近乎重复** → 只要二者同在池中，它们就相当于"一个模式占 2 份候选"，在尾部分选中天然占优；
2. **选择是最近邻/极值序统计** → 下尾的微小差异被放大：
   - truth=mpi（池 = trace + had 对）：trace 的下尾略优 → trace 独占 59%；
   - truth=trace（池 = had 对 + mpi）：had 对的下尾略优（且候选翻倍）→ 合计 80%，mpi 仅 20%。

因此并不是"trace 与 mpi 谁更近"这种均值层面的问题，而是**下尾 + 近重复对**共同作用的结果。这也再次支持：**用 had_g/had_h 之一作真值时，必须把另一个（兄弟模式）排除出先验池**，否则真值会以"兄弟模式"形式泄漏。
