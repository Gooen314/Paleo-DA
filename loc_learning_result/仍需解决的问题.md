## 0. 四个问题共用的定义与实验约定

### 0.1 数据与基座

- 真值为 MPI；先验模式池为 `{trace, had_g, had_h}`。
- 状态为 TAS，n=6144；主实验使用相同的无纬度加权类比成员选择及相同的观测、R、先验均值。
- 主基座包括 raw、GC(10000 km, inflation=1.0)、原乘性 CELF。directK 单独标记，不能把它与乘性 CELF 混称为同一个基座。
- GC 增量必须来自实际串行 EnSRF：`z_GC = xa_GC - xb`。不能用 `GC ⊙ K0` 的批量增益乘新息替代，因为带局地化的串行与批量更新一般不等价。
- 后期参考值：raw 约 0.5771，GC 约 0.5118，N4 验证集选参约 0.4632，S1 约 0.4575。它们仅用于复现核对，不作为新实验必须达到的硬门槛。
- 早期 canonical GC7500/inflation1.5 的 0.5021 属于不同配置，不与后期结果直接拼接计算改进率。

### 0.2 符号、方向与维度

对时刻 t、基座 b：

\[
d_t=y_t-H_tx_{b,t},\qquad
z_{b,t}=x^{(0)}_{a,b,t}-x_{b,t},\qquad
e_{b,t}=x_t^{\mathrm{truth}}-x^{(0)}_{a,b,t}.
\]

- `xb`：先验均值；`xa^(0)`：未经低秩修正的基座分析；`z`：基座增量。
- **误差 e 固定为“真值减分析”**，因此最终分析为 `xa = xa^(0) + e_hat`，剩余误差为 `e - e_hat`。
- Z、E 的每一列为一个时刻：`Z=[z_1,...,z_T]`、`E=[e_1,...,e_T]`，维度均为 n×T。
- D=diag(w)，`w_i=cos(lat_i)/sum_j cos(lat_j)`，全篇统一使用归一化面积权重。cos 纬度表示网格面积权重，不表示观测可信度。
- `||v||_D^2 = v^T D v`；Q 的维度为 n×r，满足 `Q^T D Q=I_r`；W 为 n×r。
- 若网格包含权重严格为零的极点，先规定并记录如何处理零权重格点，再进行 D 的逆平方根运算。

基本方法：

\[
\widehat e_{b,t}=QW^\top z_{b,t},\qquad
x_{a,b,t}=x^{(0)}_{a,b,t}+\widehat e_{b,t}.
\]

S1 为：

\[
x_{a,b,t}=x^{(0)}_{a,b,t}+\beta\widehat e_{b,t},\qquad
\beta=1-\alpha.
\]

注意：S1 的收缩是向“基座分析”回退，而不是向单独的先验均值回退。

### 0.3 评价口径

主诊断量为窗口平均加权 MSE：

\[
J=\frac1{|\mathcal T|}\sum_{t\in\mathcal T}\|e_t-\widehat e_t\|_D^2.
\]

同时报告：

\[
\overline{\mathrm{RMSE}}=\frac1{|\mathcal T|}\sum_t\sqrt{\|e_t-\widehat e_t\|_D^2},
\qquad \mathrm{RMSE}_{\mathrm{pooled}}=\sqrt J.
\]

历史报告主要使用前者。二者不相等；**误差分解、模态贡献和最优标量推导都在 MSE 上完成**。

## 问题一：基座之后，真的存在由分析增量可预测的误差吗？

### 1.1 待检验假说

核心问题是：在控制平均偏差与缓慢变化的背景后，z 是否仍能提供对 e 的额外预测信息？

应区分三件事：

1. e 的能量是否低秩；
2. e 是否能被某个输入在训练段拟合；
3. e 是否能被 z 在未参与拟合的连续时段预测。

只有第 3 项直接支持“增量条件化误差修正”的主张。误差谱本身不能完成证明。

### 1.3 分析结果的方法

**方法 A：量化 z 相对背景的增量技能。**

\[
\Delta J_{z|g}=J(\widehat e_g)-J(\widehat e_{g,z}).
\]

在连续验证与固定评估段分别计算。若只优于“不修正”而不优于常数/背景对照，不能声称学到了当前观测更新特有的信息。

**方法 B：衡量系数预测，不只看相关。**

对于模态 k，定义相对训练均值预测的技能：

\[
\mathrm{Skill}_k=1-
\frac{\sum_t(c_{k,t}-\widehat c_{k,t})^2}
{\sum_t(c_{k,t}-\bar c_{k,\mathrm{train}})^2}.
\]

中心化方案的训练均值为零。另报告相关、均值偏差和校准斜率；高相关而幅度错误仍可能增加状态 MSE。分母接近零时不解释技能比值，只报告绝对误差。

**方法 C：比较真实配对与错配关系。**

真实配对模型应在折外明显优于多数错配模型，且这种优势不能完全由趋势是否保留解释。这个检验支持预测关系，不单独证明气候因果关系。

**方法 D：检查收益时间分布。**

按预先规定的连续区间报告贡献，避免全部改善只来自极少数高误差时刻却被描述为普遍有效。

### 1.4 预估可能出现的结果及对应解释

| 可能结果 | 能支持的结论 | 后续处理 |
|---|---|---|
| z 回归在控制常数和背景后仍显著改善；错配失效 | 存在当前增量相关的可预测剩余误差 | 进入 Q2/Q3，识别其方向与基座依赖 |
| 原始 z 有效，去趋势/背景后收益基本消失 | 主要修正共同的慢变偏差或气候态关系 | 将方法定位为背景/气候态条件化订正，弱化“观测新息特有信息”的主张 |

| 训练好、所有连续验证都差 | 关系不可稳定估计或样本不足 | 检查正则、有效样本数、趋势外推；不能以训练拟合证明机制 |

**完成判据：**明确回答“是否有超出平均偏差和背景趋势的增量预测技能”，并以实际效应量、连续验证和负对照给出证据；不要求结果必须为肯定。

## 问题二：为什么 GC 能增强低秩修正？

### 2.1 待检验假说与精确分解

固定 Q，定义：

\[
P_Q=QQ^\top D,\qquad c_t=Q^\top De_t,\qquad
e_{\perp,t}=(I-P_Q)e_t.
\]

则对任意预测系数 c_hat：

\[
\boxed{
\|e_t-Q\widehat c_t\|_D^2
=\|e_{\perp,t}\|_D^2+\|c_t-\widehat c_t\|_2^2
}.
\]

基座误差为 `||e||_D^2=||e_perp||_D^2+||c||_2^2`。因此改善完全来自子空间内系数误差的下降。

对带常数订正的方案，将 e 换为 `e-mu_e` 后应用同一分解；必须明确参照基线已改变。

需要区分：

- **表示瓶颈**：大量误差在当前 Q 之外，完美系数也无法消除。
- **预测瓶颈**：误差已在 Q 内，但 z 不能可靠预测其系数。
- **估计瓶颈**：关系可能存在，但数据量与条件数使 W 估计不稳定。

### 2.2 详细 TODO list

- [ ] **Q2-06：直接分解 GC 相对 raw 的误差改变。**

  - 这是一种统计因素分离诊断，不将其表述为严格因果干预。

- [ ] **Q2-08：检查估计稳定性。**
  - 比较各基座 Z 的有效秩、奇异谱和 ridge 有效自由度。
  - 若 `sigma_j` 是中心化 Z 的奇异值，记录 `df=sum_j sigma_j^2/(sigma_j^2+η)`。
  - 在连续训练子段或时间块重采样下重复拟合，比较 B 的预测输出稳定性与系数误差，而不只比较 W 元素。

- [ ] **Q2-09：必要时再研究“采样噪声”来源。**
  - 只有在需要声称“GC 消除有限集合采样噪声”时，增加成员数或重复集合抽样的受控实验。
  - 类比池前 K 名改变会同时改变成员组成；不能把这种差异全部归因于采样噪声。
  - 更有针对性的对照是在同一预定义候选分布中重复抽样、与较大集合参照比较，并记录均值变化。
  - 如果不做该实验，结论限制为“GC 改善了某类子空间外误差/可预测性”，不强行命名误差来源。

- [ ] **Q2-10：输出机制图表。**
  - 堆叠图：基座误差、oracle 不可修正项、实际系数误差。
  - r 扫描图：J_perp、J_coef、G_Q 随秩变化。
  - 2×2 热图：输入与目标交叉预测误差。
  - GC 相对 raw 的空间内/外改善分解及条件数、稳定性统计。

### 2.3 分析结果的方法

1. **先看公共 Q 的结果，再看各自 Q 的结果。**前者隔离基座差异，后者检查公平性和可达上限，不能只展示对论点有利的一种。
2. **结合 oracle 和实际预测。**oracle 显著改善只能证明空间容量足够，不能证明部署可实现；实际逼近 oracle 才说明系数可预测。
3. **使用 2×2 回归判断输入与目标变化。**若 z_GC 对两个目标都更好，支持输入条件改善；若两个输入都更容易预测 c_GC，支持剩余误差目标更可预测。
4. **检查训练样本敏感性。**如果 raw 在强正则或更多训练样本下追平，主要可能是估计问题，而非不可修正的结构问题。
5. **避免从 rank 推导误差来源。**低秩可以来自趋势、偏差或物理结构；高秩也不自动等于噪声。

### 2.4 预估可能出现的结果及对应解释

| 可能结果 | 能支持的结论 | 对最终公式的影响 |
|---|---|---|
| raw 的 J_perp 很高，GC 显著降低 J_perp，且各自基下仍成立 | GC 解决了当前低秩容量之外的一部分误差 | 保留 GC+低秩的互补结构具有明确依据 |
| 两者 oracle 接近，但 raw 的 J_coef 高 | 主要瓶颈是系数预测或估计，不是输出空间容量 | 重点解释 GC 如何改变增量的可靠性，避免“高秩噪声”定论 |
| z_GC 对两个目标都好，而 z_raw 对两者都差 | GC 增量是更可靠的统计预测输入 | 将 GC 解释为改善增量表示/条件的步骤 |
| 两种输入对 c_GC 都好，对 c_raw 都差 | GC 让剩余误差更容易预测 | 解释为误差目标结构被改变，而非只对输入去噪 |
| raw 换成分析误差基或可预测基后明显追平 | 原固定先验误差基对 raw 不合适 | “必须依赖 GC”应被撤回或收窄 |
| raw 只在大 η 下追平，且重采样不稳定性下降 | 小样本病态估计占主导 | 优先解决正则与低维输入，而不是增加基座复杂度 |
| 子空间外误差和系数误差都改善 | GC 与低秩修正存在多方面互补 | 按分解量报告两种贡献，不用单一口号概括 |

**完成判据：**能够量化 GC 的优势有多少来自表示空间、有多少来自系数预测/估计，并明确哪些机制仍未被辨识。

## 问题三：Q、W 究竟在做什么？

### 3.1 数学含义与需要修正的表述

给定固定的 D-正交 Q：

\[
c_t=Q^\top De_t,\qquad \widehat c_t=W^\top z_t.
\]

W 是从分析增量预测“剩余误差在 Q 中的幅度”的线性编码器，不是 Q 的正交投影矩阵。无截距 ridge 解为：

\[
\boxed{W^\top=CZ^\top(ZZ^\top+\eta I)^{-1}}.
\]

中心化版本用 `Z_c=Z-mu_z 1^T`、`E_c=E-mu_e 1^T`、`C_c=Q^T D E_c`，并在最终修正中加回 mu_e。

- 未中心化的乘积是二阶矩，不能一概称为协方差。
- U、V 同时学习是非凸双线性优化；固定 Q 后学习 W 才是凸二次问题。
- `rank(UV^T)<=r`，但 `I+UV^T` 一般为满秩，且其对角一般不严格等于 1。
- 固定非零 Q 时，W=0 一般也有非零梯度；“U、V 同时为零的鞍点”不能套用于只学 W 的情况。
- 左乘有效增益可解释为代数上的交叉协方差修正，但不自动对应一个自洽、对称正定的完整先验协方差。本文不预设已构造了新的标准 Kalman 协方差更新。

\min_{\operatorname{rank}(B)\le r}
\|D^{1/2}(E-BZ)\|_F^2
+\eta\|D^{1/2}B\|_F^2.
\]

\[
A=ZZ^\top+\eta I,\qquad
M=D^{1/2}EZ^\top A^{-1/2}.
\]

  - 闭式最优预测算子：

\[
\boxed{B^\star=D^{-1/2}[M]_r A^{-1/2}},
\qquad x_a=x_a^{(0)}+B^\star z.
\]

  - `[M]_r` 是最佳秩-r 截断；它选择与增量有关的可预测误差方向，不等于直接对 E 做截断。

Q_{\mathrm{predictable}}=D^{-1/2}L_r,\qquad
W^\top=\Sigma_r R_r^\top A^{-1/2}.
\]

### 3.3 分析结果的方法

**方法 A：区分“能量大”与“可预测”。**比较 Q_analysis 与 Q_predictable 的误差能量、系数预测误差和实际净改善。高能量、低技能的方向不应因为解释漂亮就进入最终主模型。

**方法 B：同时检查预测方向与校准幅度。**采用 Q1 的系数技能以及 `Delta J_k`；正相关但幅度过大可导致负贡献。

**方法 C：检验嵌套算子。**在共同 Q 下，只有全矩阵显著优于对角才能支持跨模态耦合；只有全状态读出优于 Q 内读出才能支持使用输出子空间之外的信息。

**方法 D：优先解释稳定子空间。**若单个模态旋转但总 B 的预测稳定，结论应表述为“稳定的低维子空间”，而不是“唯一规范物理基”。

**方法 E：分清经验等价与理论等价。**固定 Q 的表现接近自由 U，只能说明当前样本和配置下约束成本较小；不能单凭一次 0.0012 的差值断言所有情况下 U 都无需学习。

\[
J(\beta)=\frac1T\sum_t\|e_t-\beta h_t\|_D^2.
\]

  - 无约束闭式系数：

\[
\boxed{\beta^\star=
\frac{\sum_t h_t^\top De_t}{\sum_t h_t^\top D h_t}}.

  - 检查校准段 `sum <e,h>` 与 `sum ||h||^2`，以及不同连续验证折估计的 β。
  - 报告 β 的稳定性和分段校准情况；不得用评估段 β 作为可部署参数。
  - 评估段最优 β 仅作为“还有多少幅度失配”的诊断上限，与部署结果分开。

- [ ] **Q4-06：检查是否只有少数模态需要收缩。**
  - 在 D-正交输出基下，模态校准的无约束系数为：

\[
\beta_k^\star=
\frac{\sum_t c_{k,t}\widehat c_{k,t}}
{\sum_t\widehat c_{k,t}^2}.
\]

  - 先作为诊断，识别是否少数模态过激；不能因为逐模态校准在 50 步校准集上更低就作为主方案。
  - 若要部署，需限制参数数目、向全局 β 收缩并用内部折验证；否则保留一个全局标量。

- [ ] **Q4-07：用相同最终校准方案比较基座混合。**
  - 在 GC 单基座已充分优化后，再与 GC/directK 混合加修正比较。
  - 若混合在加低秩后没有稳定额外收益，删除混合模块，不因“hybrid”叙述更好听而保留。
  - 如使用串行 GC 的等效增量与 directK 增量混合，清楚写成增量混合；只有构造了与原始新息对应的等效增益后才使用增益混合公式。

- [ ] **Q4-08：检查统计收益是否值得增加复杂度。**
  - 对新增模块计算成对损失差及时间块区间、训练折一致性、运行成本与参数增量。
  - 若多个方法在不确定性范围内接近，按预先规定的简约原则选更简单的方法。
  - 可采用“性能处于最佳内部验证误差的不确定性范围内时，选更低秩/更少自由度模型”的规则；具体阈值在看最终评估结果前固定。

- [ ] **Q4-09：完成数值与实现核验。**
  - 核验零修正能复现基座，矩阵因子计算与显式小规模 B 计算一致。
  - 核验误差分解、ridge 正规方程残差、RRR 的目标值、β 的解析值与一维数值搜索一致。
  - 对 λ=0 的欠定问题使用明确的最小范数伪逆诊断，不能把病态普通逆导致的爆炸当作所有无正则 LS 必然失败的证明。
  - 用稳定解法与数据类型排除纯数值原因后，再解释科学差异。

- [ ] **Q4-10：收束最终公式与叙述。**
  - 只保留实验证明必要的项，明确它是否满足零新息/零增量时零修正的约束。
  - 记录每个参数的估计目标、所用数据和维度，注明推断时不需要真值。
  - 最终表达可为 `xa=xa_GC+B_r z_GC`，或确有证据时使用 `xa=xa_GC+mu_e+beta B_r(z_GC-mu_z)`；两者含义不同，由实验决定，不预先指定胜者。
  - 若 raw 的统一降秩回归已经追平 GC 路线，则相应删除“GC 是必要前置”的表述。
  - 输出最终主表、复杂度表、模型选择记录、机制贡献图及未解决问题清单。

### 4.3 分析结果的方法

1. **按嵌套结构归因。**M1→中心化线性模型检验动态信息；标量/对角→低秩检验空间耦合；M3→M4 检验固定模态基下的混合；M4→M5 检验全状态输入；M5→M6 检验输出基的选择。
2. **将收益与代价并列。**给出验证及固定评估误差、时间块区间、参数量、拟合耗时、每步计算量和监督数据需求，不只按最低测试数字排序。
3. **把 β 当作校准参数检查。**β<1 可能表示预测修正幅度偏大，也可能补偿方向误差和验证分布变化；只有系数诊断同时支持时，才称为系统性过激。
4. **检查正则与 β 的互补。**ridge 按输入奇异方向进行非均匀收缩，β 做统一缩放，两者不一般等价；但在实际数据上可能高度冗余，需要实验确认。
5. **不给“闭式解”过高保证。**闭式解对指定训练目标最优，并不保证对未知测试误差最优；正则和校准仍须独立选择。

### 4.4 预估可能出现的结果及对应解释

| 可能结果 | 建议保留的最简方案 | 科学表述 |
|---|---|---|
| 常数偏差订正已解释绝大部分收益 | GC+常数订正 | 主要改善来自系统偏差，复杂低秩结构未被证明必要 |
| 标量/对角即可追平低秩 | 相应简单缩放或对角映射 | 收益主要来自幅度/局地偏差，不能强调非局地混合 |
| r×r 模态耦合追平 n×r W | GC+固定基+小矩阵回归 | 少数误差模态的耦合已足够，可解释性更强 |
| 固定基 ridge≈RRR≈自由 UV | GC+固定基 ridge | 自由基和复杂优化不是主要收益来源 |
| RRR 稳定优于固定基 | GC+正则降秩回归 | 从预测关系选择输出子空间具有明确价值 |
| 联合选 r、η 后 β≈1 或不再改善 | 删除独立 α/β | 旧 S1 的额外收益主要补偿此前估计/正则失配 |
| β 稳定小于 1，且独立校准持续改善 | 保留一个全局 β | 预测修正需要幅度校准，但不必称为新协方差 hybrid |
| 只有少数模态 β_k 偏离 1 | 优先检查秩和正则；必要时少量模态收缩 | 全局 α 掩盖了特定模态的校准问题 |
| 神经网络/混合基座无稳定额外收益 | 删除相应模块 | 主要结果来自统计误差结构而非网络表达力 |
| 简化后 raw 也能追平 GC | 考虑 raw+简化回归 | “必须 GC 前置”是当前参数化限制，而非一般机制 |

**完成判据：**得到一条每个保留模块都有独立证据的最终公式；允许最终误差略高于历史最优，但要求含义明确、选参透明、结果可复现。

### 5.3 期望形成的科学逻辑链

> 基座同化产生分析与增量 → 确认剩余误差中存在超出简单背景的可预测部分 → 分解 GC 改变了哪些误差分量与预测条件 → 从误差—增量关系识别可预测子空间 → 正则回归估计修正系数 → 仅在必要时进行幅度校准 → 用嵌套消融保留最小结构。
